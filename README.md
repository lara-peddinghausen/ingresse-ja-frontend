## Ingresse Já Frontend - Angular

**IMPORTANTE: ACESSO AO CÓDIGO ATUALIZADO**  
Os arquivos e a implementação final deste projeto encontram-se na branch: **front-branch**  
**[Clique aqui para acessar a front-branch](https://github.com/lara-peddinghausen/ingresse-ja-frontend/tree/front-branch)**

Projeto de uma plataforma digital desenvolvida para facilitar a compra e gestão de ingressos online. Esta é a interface web da plataforma. A aplicação consome a API REST desenvolvida em Java para processar usuários, ingressos, eventos e cupons.

**Informação:** Este repositório representa uma entrega parcial do projeto proposto.

Este projeto foi desenvolvido como parte da disciplina **Projeto Integrador III**, utilizando como base o projeto fornecido pelo professor **Reinaldo José de Freitas** (reinaldo.freitas@rj.senac.br). 

Este projeto funciona em conjunto com o [ingresse-ja-backend](https://github.com/lara-peddinghausen/ingresse-ja-backend).

**Framework:** Angular 19.  
**UI Components:** Angular Material (MatDialog, MatButton, etc).  
**Comunicação:** HttpClient para consumo da API REST com suporte a CORS.  
**Segurança:** Implementação de guarda de rotas (rotas protegidas) para Home e páginas de gestão.
